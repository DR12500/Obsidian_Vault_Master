### Ground-Truth & Circuit Discovery Benchmarks
- [InterpBench](https://proceedings.neurips.cc/paper_files/paper/2024/file/a8f7d43ae092d9a5295775eb17f3f4f7-Paper-Datasets_and_Benchmarks_Track.pdf#:~:text=0.8.%201.0.%20Correlation%20Coefficient.%20siit%20v%2Fs%20nat.,on%20IIT%20and%20SIIT%20models%2C%20respectively.%20%7B%22isScientific%22%3Atrue%2C%22citationCount%22%3A0%2C%22authors%22%3A%5B%5D%2C%22doi%22%3A%22%22%2C%22issuedYear%22%3A0%2C%22publisher%22%3A%22%22%2C%22containerTitle%22%3A%22%22%2C%22title%22%3A%22%22%2C%22page%22%3A%22%22%2C%22volume%22%3A%22%22%2C%22abstract%22%3A%22%22%7D) / Tracr
	- Built on top of **Tracr** (a compiler that translates human code written in RASP into Transformer weights). **InterpBench** provides a suite of models with known, compiled ground-truth circuits. It allows researchers to test if automated tools accurately discover the exact underlying code embedded in the weights.
- [**MIB (Mechanistic Interpretability Benchmark**)](https://www.alphaxiv.org/abs/2504.13151#:~:text=This%20makes%20it%20methodologically%20critical%20for%20the,Conference%20on%20Learning%20Representations%2C%202025.%20URL%20https%3A%2F%2Fopenreview.net%2Fforum%3Fid%3DI4e82CIDxv.) **is a really good starting point**
	- A standardized, multi-model evaluation framework designed to benchmark **circuit localization** (finding subgraphs) and **causal variable localization** (aligning neural features with concepts using metrics like _Interchange Intervention Accuracy_). 
		- [[Data]] from [Huggingface](https://huggingface.co/collections/mib-bench/mib-datasets-67f55273612ec3067a42a56b)
### Feature Disentanglement & Dictionary Learning Benchmarks (SAE)
- [SAEBench](https://icml.cc/virtual/2025/poster/43918#:~:text=By%20providing%20a%20standardized%20framework%20for%20measuring,Code%20and%20models%20available%20at%3A%20github.%20com%2Fadamkarvonen%2FSAEBench.)
	- A standardized evaluation suite for Sparse Autoencoders. In addition to the usual proxy metrics (sparsity and reconstruction, the "Core" metric), SAEBench tests SAEs across practical dimensions: interpretability, **feature disentanglement**, probing and unlearning. Its eight metrics: Core (L0, loss recovered), Automated Interpretability, Sparse Probing, RAVEL, Feature Absorption, Unlearning, Spurious Correlation Removal, Targeted Probe Perturbation. (No circuit-reconstruction metric.)
- [RAVEL](https://www.alphaxiv.org/replicate/2402.17700) (Disentangling Attribute-Value Representatioins)
	- Evaluates how well interpretability methods isolate specific semantic concepts within activation space without collateral damage (i.e., verifying that modifying one conceptual attribute does not corrupt orthogonal knowledge).
